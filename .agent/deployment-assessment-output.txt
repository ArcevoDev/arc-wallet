ready for wallet development today.

- SSRF defense, CORS restricted, CSRF protection
- Email via Resend (13 templates), SMS via Brevo
- Audit logging (40+ actions)
- CI pipeline (lint -> typecheck -> test -> build)
- Dockerfile (multi-stage, node:22-alpine) + docker-compose.yml
