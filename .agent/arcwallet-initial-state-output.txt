1. OVERVIEW
-----------
ArcWallet is an Expo 57 + React Native 0.86 mobile wallet application.
Currently in its default Expo starter template state — NO arc-id
integration has been implemented yet. This is a greenfield build.

Tech stack: Expo 57, React Native 0.86, expo-router (file-based routing),
react-native-reanimated 4.5, TypeScript 6.0, pnpm (hoisted linker).

3. CURRENT SCREENS (app/)
--------------------------
src/app/_layout.tsx:
  - Root layout for expo-router
  - Wraps everything in ThemeProvider (DarkTheme / DefaultTheme)
  - Shows AnimatedSplashOverlay then renders AppTabs

src/app/index.tsx (Home):
  - Hero section with AnimatedIcon + "Welcome to Expo" title
  - HintRow for "edit index.tsx", "Dev tools", "Fresh start"
  - Web badge with Expo version
  - Uses SafeAreaView + themed components

src/app/explore.tsx (Explore):
  - Documentation links and learning resources
  - Collapsible sections: file-based routing, cross-platform, images, dark mode, animations
  - ExternalLink to Expo docs
  - Uses SymbolView from expo-symbols

4. COMPONENT INVENTORY
-----------------------
ThemedText           - Typography component with variants (default, title, subtitle, small, etc.)
ThemedView           - View wrapper with theme-aware backgroundColor
ThemedView types     - background, backgroundElement, backgroundSelected, text, textSecondary
AnimatedIcon         - Reanimated keyframe animations for splash transition
AnimatedSplashOverlay - Full-screen splash that fades out
AppTabs              - NativeTabs (iOS/Android) or custom Tabs (web)
Collapsible          - Animated expand/collapse with chevron
ExternalLink         - In-app browser via expo-web-browser
HintRow              - Row with title + code-snippet hint
WebBadge             - Expo version badge (web only)

5. THEME SYSTEM

8. CURRENT GAPS (vs wallet requirements)
------------------------------------------
- No authentication (login/register/logout)
- No session management
- No credential storage or display
- No DID wallet functionality
- No API client or SDK integration
- No secure storage (no expo-secure-store)
- No QR code scanning (no expo-camera or bar-code-scanner)
- No network request layer
- No state management beyond theme hooks
- No navigation to wallet-specific screens
- No biometric auth integration
