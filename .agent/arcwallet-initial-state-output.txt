1. OVERVIEW
-----------
ArcWallet is an Expo 57 + React Native 0.86 mobile wallet application.
Currently in its default Expo starter template state - NO arc-id
integration has been implemented yet. This is a greenfield build.

Tech stack: Expo 57, React Native 0.86, expo-router (file-based routing),
react-native-reanimated 4.5, TypeScript 6.0, pnpm (hoisted linker).

3. CURRENT SCREENS (app/)
--------------------------
src/app/_layout.tsx:
  - Root layout for expo-router
  - Wraps everything in ThemeProvider (DarkTheme / DefaultTheme)
  - Shows AnimatedSplashOverlay then renders AppTabs

src/app/index.tsx (Home):
  - Hero section with AnimatedIcon + 'Welcome to Expo' title
  - HintRow for 'edit index.tsx', 'Dev tools', 'Fresh start'
  - Web badge with Expo version

src/app/explore.tsx (Explore):
  - Documentation links and learning resources
  - Collapsible sections: file-based routing, cross-platform, images, animations

4. COMPONENT INVENTORY (Expo starter set - all web/native presentational)

6. CURRENT GAPS (vs wallet requirements)
---------------------------------------
- No authentication (login/register/logout)
- No session management
- No credential storage or display
- No DID wallet functionality
- No API client or SDK integration
- No secure storage (no expo-secure-store)
- No QR code scanning (no expo-camera)
- No state management beyond theme hooks
- No wallet-specific screens or navigation
- No biometric auth integration

7. NOTABLE: WHAT IS READY TO CONSUME (verified 2026-08-05)
-----------------------------------------------------------
The wallet does not need to port the arc-id SDK. The published
@arcevo/facet-sdk (npm, v1.0.1) is pure fetch + framework-agnostic and
covers auth, passkeys, credentials (VCs), onboarding, wallet-DID,
tenants, billing, webhooks, audit, and IdP. arc-id itself consumes this
same SDK package (src/sdk/index.ts is a singleton wrapper around it).

The wallet adds: zustand, expo-secure-store, expo-camera, and its own
React Native screens. The web-only facet packages (components/auth/
layout) are NOT usable in React Native.
